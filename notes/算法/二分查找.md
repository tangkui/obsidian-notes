> 二分查找的前提是数组必须是**有序**的
> 二分查找的时间复杂度为O(logn)，每次都会排除一半的数据

```java
// 二分查找：每次排除一半数据
public int binarySearch(int[] arr, int target) {
    int left = 0, right = arr.length - 1;
    
    while (left <= right) {
        int mid = left + (right - left) / 2;
        
        if (arr[mid] == target) {
            return mid;           // 找到了
        } else if (arr[mid] < target) {
            left = mid + 1;       // 目标在右半部分，丢弃左半
        } else {
            right = mid - 1;      // 目标在左半部分，丢弃右半
        }
    }
    return -1;
}
```
**为什么是对数？**
- N=16：找4次（$2^{4}=16$）（16→8→4→2→1）
- N=1024：找10次（$2^{10}=1024$）
- 公式：$\log_2 N$
