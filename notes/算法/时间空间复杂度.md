# 算法复杂度分析笔记（修正版）

## 一、核心概念速览

| 符号 | 含义 | 通俗理解 |
|:---|:---|:---|
| **O** | 大O符号 (Big O) | 描述算法**最坏情况**下的增长趋势 |
| **N** | 问题规模/输入数据量 | 比如数组长度、节点数量 |
| **logN** | 对数复杂度 | 每次操作都能把问题规模**减半** |

---

## 二、时间复杂度 (Time Complexity)

### 2.1 什么是时间复杂度？

> 衡量算法**执行时间随数据规模增长的变化趋势**，不是具体的秒数。

**关键理解：**
- 忽略常数和低阶项：$O(2N + 100)$ 简化为 $O(N)$
- 关注**最坏情况**：保证算法不会比这个更慢
- 描述的是**趋势**，不是精确时间

### 2.2 常见时间复杂度对比（从快到慢）

```
O(1) < O(logN) < O(N) < O(NlogN) < O(N²) < O(2^N) < O(N!)
```

| 复杂度 | 名称 | N=10时的操作次数 | N=1000时的操作次数 |
|:---|:---|:---|:---|
| $O(1)$ | 常数 | 1 | 1 |
| $O(\log N)$ | 对数 | ~3 | ~10 |
| $O(N)$ | 线性 | 10 | 1000 |
| $O(N \log N)$ | 线性对数 | ~30 | ~10,000 |
| $O(N^2)$ | 平方 | 100 | 1,000,000 |
| $O(2^N)$ | 指数 | 1024 | 天文数字 |

### 2.3 Java代码示例详解

#### $O(1)$ — 常数时间
```java
// 无论数组多大，只取第一个元素
public int getFirst(int[] arr) {
    return arr[0];  // 1次操作
}

// 通过索引直接访问HashMap
public boolean containsKey(HashMap<String, Integer> map, String key) {
    return map.containsKey(key);  // 平均O(1)
}
```
**特点：** 与数据规模无关，最快

---

#### $O(\log N)$ — 对数时间
```java
// 二分查找：每次排除一半数据
public int binarySearch(int[] arr, int target) {
    int left = 0, right = arr.length - 1;
    
    while (left <= right) {
        int mid = left + (right - left) / 2;
        
        if (arr[mid] == target) {
            return mid;           // 找到了
        } else if (arr[mid] < target) {
            left = mid + 1;       // 目标在右半部分，丢弃左半
        } else {
            right = mid - 1;      // 目标在左半部分，丢弃右半
        }
    }
    return -1;
}
```
**为什么是对数？**
- N=16：找4次（16→8→4→2→1）
- N=1024：找10次（$2^{10}=1024$）
- 公式：$\log_2 N$

---

#### $O(N)$ — 线性时间
```java
// 遍历数组找最大值
public int findMax(int[] arr) {
    int max = arr[0];
    for (int i = 1; i < arr.length; i++) {  // 循环N次
        if (arr[i] > max) {
            max = arr[i];
        }
    }
    return max;
}

// 遍历链表
public int sumList(Node head) {
    int sum = 0;
    Node current = head;
    while (current != null) {  // 遍历N个节点
        sum += current.val;
        current = current.next;
    }
    return sum;
}
```
**特点：** 操作次数与数据量成正比

---

#### $O(N \log N)$ — 线性对数时间
```java
// 归并排序：分治思想的典型
public void mergeSort(int[] arr, int left, int right) {
    if (left < right) {
        int mid = left + (right - left) / 2;
        
        mergeSort(arr, left, mid);      // 递归左半：T(N/2)
        mergeSort(arr, mid + 1, right); // 递归右半：T(N/2)
        merge(arr, left, mid, right);   // 合并：O(N)
    }
}

// 总复杂度：N层 × 每层O(N) = O(N log N)
```
**为什么是 $N \log N$？**
- 递归深度：$\log N$ 层（每次对半分）
- 每层工作量：合并需要 $O(N)$
- 相乘得：$N \times \log N$

---

#### $O(N^2)$ — 平方时间
```java
// ✅ 冒泡排序：双重循环，相邻元素比较交换
public void bubbleSort(int[] arr) {
    int n = arr.length;
    for (int i = 0; i < n - 1; i++) {           // 外层N次
        for (int j = 0; j < n - i - 1; j++) {   // 内层约N次
            if (arr[j] > arr[j + 1]) {           // 相邻比较
                // 交换
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
            }
        }
    }
}

// 打印所有数对
public void printAllPairs(int[] arr) {
    for (int i = 0; i < arr.length; i++) {
        for (int j = 0; j < arr.length; j++) {
            System.out.println(arr[i] + "," + arr[j]);
        }
    }
}
```
**特点：** 双重循环嵌套，数据量翻倍→时间变为4倍

---

#### $O(2^N)$ — 指数时间（慎用！）
```java
// 斐波那契数列：暴力递归
public int fibonacci(int n) {
    if (n <= 1) return n;
    return fibonacci(n - 1) + fibonacci(n - 2);  // 每次分裂成2个
}

// 递归树：第N层有 2^N 个节点
```
**优化方案：** 使用记忆化搜索或动态规划降为 $O(N)$

### 2.4 时间复杂度分析技巧

```java
// 技巧1：找最深层循环
public void example(int[] arr) {
    // O(1) 部分
    int a = arr[0];
    
    // O(N) 部分
    for (int x : arr) { ... }
    
    // O(N²) 部分 - 这是瓶颈！
    for (int i = 0; i < arr.length; i++) {
        for (int j = 0; j < arr.length; j++) { ... }
    }
    
    // 总复杂度 = O(N²) （取最高阶）
}
```

```java
// 技巧2：多个独立循环是相加，嵌套是相乘
public void analyze(int[] arr) {
    // 情况A：顺序执行（取最大）
    for (...) {} // O(N)
    for (...) {} // O(N)
    // 结果：O(N) + O(N) = O(N)
    
    // 情况B：嵌套（相乘）
    for (...) {
        for (...) {} 
    }
    // 结果：O(N) × O(N) = O(N²)
}
```

## 三、空间复杂度 (Space Complexity)

### 3.1 什么是空间复杂度？

> 衡量算法**运行过程中额外占用内存随数据规模的增长趋势**。

**注意：** 不包括输入数据本身占用的空间，只算**算法额外申请**的空间。

### 3.2 常见空间复杂度

| 复杂度 | 场景 | Java示例 |
|:---|:---|:---|
| $O(1)$ | 只用固定几个变量 | 冒泡排序、数组反转、二分查找 |
| $O(N)$ | 申请同等规模的数组 | 复制数组、线性递归 |
| $O(N^2)$ | 二维矩阵 | 动态规划表 |
| $O(\log N)$ | 递归调用栈 | 二分查找递归版 |

### 3.3 Java代码示例详解

#### $O(1)$ — 常数空间
```java
// ✅ 求和：只使用固定数量的变量
public int sum(int[] arr) {
    int total = 0;                    // 1个变量
    for (int i = 0; i < arr.length; i++) {
        total += arr[i];
    }
    return total;
}

// ✅ 数组原地反转：首尾交换，不额外申请空间
public void reverseInPlace(int[] arr) {
    int left = 0, right = arr.length - 1;  // 2个变量
    while (left < right) {
        int temp = arr[left];           // 1个临时变量
        arr[left] = arr[right];
        arr[right] = temp;
        left++;
        right--;
    }
}

// ✅ 冒泡排序：空间O(1)（原地排序）
public void bubbleSort(int[] arr) {
    int n = arr.length;
    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - i - 1; j++) {
            if (arr[j] > arr[j + 1]) {
                int temp = arr[j];      // 仅用1个临时变量
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
            }
        }
    }
}
```
**特点：** 无论数据多大，内存使用不变

---

#### $O(N)$ — 线性空间
```java
// 复制数组
public int[] copyArray(int[] arr) {
    int[] newArr = new int[arr.length];  // 申请N个空间
    for (int i = 0; i < arr.length; i++) {
        newArr[i] = arr[i];
    }
    return newArr;
}

// 递归的调用栈空间（线性递归）
public int factorial(int n) {
    if (n <= 1) return 1;
    return n * factorial(n - 1);  // 递归深度N，每层栈帧O(1)
}
// 空间：O(N) - 因为同时存在N个未返回的函数调用
```

---

#### $O(N^2)$ — 平方空间
```java
// 创建二维数组
public int[][] createMatrix(int n) {
    int[][] matrix = new int[n][n];  // N × N = N²个元素
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) {
            matrix[i][j] = i * j;
        }
    }
    return matrix;
}

// 动态规划：最长公共子序列表
public int lcs(String s1, String s2) {
    int m = s1.length(), n = s2.length();
    int[][] dp = new int[m + 1][n + 1];  // O(m×n) 空间
    
    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (s1.charAt(i-1) == s2.charAt(j-1)) {
                dp[i][j] = dp[i-1][j-1] + 1;
            } else {
                dp[i][j] = Math.max(dp[i-1][j], dp[i][j-1]);
            }
        }
    }
    return dp[m][n];
}
```

#### $O(\log N)$ — 对数空间
```java
// 二分查找递归版：递归深度logN
public int binarySearchRecursive(int[] arr, int target, int left, int right) {
    if (left > right) return -1;
    
    int mid = left + (right - left) / 2;
    
    if (arr[mid] == target) {
        return mid;
    } else if (arr[mid] < target) {
        return binarySearchRecursive(arr, target, mid + 1, right);
    } else {
        return binarySearchRecursive(arr, target, left, mid - 1);
    }
}
// 同时存在的栈帧最多 log₂N 个
```

## 四、时间与空间的权衡 (Trade-off)

### 4.1 经典权衡案例

#### 案例1：斐波那契数列
```java
// 方案A：时间优先（DP）- 时间O(N)，空间O(N)
public int fibDP(int n) {
    if (n <= 1) return n;
    int[] dp = new int[n + 1];  // 空间O(N)
    dp[1] = 1;
    for (int i = 2; i <= n; i++) {
        dp[i] = dp[i-1] + dp[i-2];  // 时间O(N)
    }
    return dp[n];
}

// 方案B：空间优化 - 时间O(N)，空间O(1)
public int fibOptimized(int n) {
    if (n <= 1) return n;
    int prev2 = 0, prev1 = 1;  // 只保留前两个值
    for (int i = 2; i <= n; i++) {
        int current = prev1 + prev2;
        prev2 = prev1;
        prev1 = current;
    }
    return prev1;
}
```

#### 案例2：两数之和
```java
// 方案A：暴力法 - 时间O(N²)，空间O(1)
public int[] twoSumBrute(int[] nums, int target) {
    for (int i = 0; i < nums.length; i++) {
        for (int j = i + 1; j < nums.length; j++) {
            if (nums[i] + nums[j] == target) {
                return new int[]{i, j};
            }
        }
    }
    return null;
}

// 方案B：HashMap - 时间O(N)，空间O(N)
public int[] twoSumHash(int[] nums, int target) {
    HashMap<Integer, Integer> map = new HashMap<>();  // 空间换时间
    for (int i = 0; i < nums.length; i++) {
        int complement = target - nums[i];
        if (map.containsKey(complement)) {
            return new int[]{map.get(complement), i};
        }
        map.put(nums[i], i);
    }
    return null;
}
```

### 4.2 权衡决策指南

| 场景 | 推荐策略 | 原因 |
|:---|:---|:---|
| 数据量小（N<1000） | 优先时间优化 | 空间成本低 |
| 内存受限（嵌入式） | 优先空间优化 | 内存是瓶颈 |
| 高频调用 | 优先时间优化 | 累积效应大 |
| 低频调用 | 优先空间优化 | 单次影响不大 |
| 实时系统 | 优先时间优化 | 响应速度关键 |

### 6.1 时间复杂度判断口诀

```
单循环看边界，双循环看嵌套
递归看深度，分治看合并

```

## 七、常见误区纠正

| 误区 | 真相 |
|:---|:---|
| "我的代码只有10行，复杂度肯定低" | 行数与复杂度无关，看循环和递归 |
| "运行快就是复杂度低" | 可能是测试数据小，要看趋势 |
| "递归比循环慢" | 时间复杂度相同，只是常数因子不同 |
| "空间复杂度包括输入数据" | 只算**额外**空间，不算输入本身 |
| "O(N)总是比O(logN)好" | 小数据量时O(N)可能更快（常数小） |

## 八、面试高频考点

### 8.1 快速判断技巧
1. **看到`while (left <= right)`** → 可能是 $O(\log N)$
2. **看到嵌套循环** → 大概率是 $O(N^2)$ 或更高
3. **看到递归调用两次** → 可能是 $O(2^N)$，考虑优化
4. **看到排序后处理** → 整体至少是 $O(N \log N)$

### 8.2 手写分析示例
```java
// 面试题：分析以下代码复杂度
public void foo(int[] arr) {
    int n = arr.length;
    for (int i = 0; i < n; i += 2) {      // 循环N/2次 → O(N)
        System.out.println(arr[i]);
    }
    
    for (int i = 1; i < n; i *= 2) {      // i:1,2,4,8... → O(log N)
        System.out.println(arr[i]);
    }
}

// 答案：时间O(N) + O(log N) = O(N)，空间O(1)
```
