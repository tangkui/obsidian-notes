| 缩写      | 全称                       | 核心作用   | 解决什么问题             |
| ------- | ------------------------ | ------ | ------------------ |
| **ICP** | Index Condition Pushdown | 索引条件下推 | 减少**无效回表**次数       |
| **MRR** | Multi-Range Read         | 多范围读   | 把**随机回表**变**顺序回表** |
| **BKA** | Batched Key Access       | 批量键访问  | 批量回表，减少**离散IO**    |
